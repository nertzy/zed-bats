# Security Policy

## Supported versions

Only the latest commit on `main` receives security fixes until the first release; after that, only the latest published version.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's security advisory form](https://github.com/nertzy/zed-bats/security/advisories/new). Include the affected commit or version, impact, and a minimal reproduction when possible.

Please do not open a public issue for an undisclosed vulnerability. Acknowledgment and follow-up will happen in the private advisory.
