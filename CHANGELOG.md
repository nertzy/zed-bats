# Changelog

Notable changes to `zed-bats` are documented here.

## [Unreleased]

### Added

- Added a Bats language for `.bats` files and files with a `bats` shebang, using the tree-sitter-bats grammar.
- Added run buttons that run a single test or the whole file with `bats`.
- Added highlighting (tree-sitter-bats's own query), outline, Vim text objects, brackets, indentation, comment injections, and redactions.
